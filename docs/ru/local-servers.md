# Локальные OpenAI-совместимые серверы (vLLM, llama-swap)

[English version](../en/local-servers.md)

Провайдер `vllm` работает с любым OpenAI-совместимым сервером: vLLM,
llama-swap и подобными. Для обычных моделей используется
`/v1/chat/completions`, для моделей TranslateGemma есть отдельная обработка.

## Настройка

```yaml
default_provider: vllm

settings:
  timeout: 300          # загрузка модели в llama-swap может занимать минуты

providers:
  vllm:
    base_url: http://localhost:8000/v1   # обязательно
    model: translategemma-12b            # обязательно
    api_key: ""                          # необязательно
```

То же через командную строку:

```bash
llm-translate -p vllm -u http://localhost:8000/v1 -m translategemma-12b \
  -f en -t ru -i text.md --timeout 300
```

### Таймаут

llama-swap загружает модель при первом запросе. В наших тестах модель на 27B
загружалась 160-200 секунд, поэтому со стандартным `timeout: 60` запрос
падает с `context deadline exceeded`. Ставьте `timeout: 300` или держите
модель загруженной.

## TranslateGemma

Провайдер считает модель TranslateGemma, если в её имени есть
`translategemma` (без учёта регистра).

Перевод:

- Запрос состоит из одного `user`-сообщения с `source_lang_code`,
  `target_lang_code` и текстом, как требует чат-шаблон модели.
- Исходный язык нужно указывать явно: `--from auto` не поддерживается.
- `--style`, `--context` и глоссарии не поддерживаются.

Анализ текста:

- Работают все виды анализа.
- Запросы идут в `/v1/completions` с промптом в формате Gemma в обход
  строгого чат-шаблона модели.

## Модели с рассуждениями (Qwen3 и подобные)

Рассуждения могут израсходовать весь лимит `max_tokens`, и анализ
вернётся пустым. Чтобы отключить рассуждения, передайте серверу
`chat_template_kwargs`:

```yaml
providers:
  vllm:
    base_url: http://localhost:8000/v1
    model: qwen3.8-27b
    chat_template_kwargs:
      enable_thinking: false
```

`chat_template_kwargs` передаётся в теле запроса без изменений.
Поддерживается провайдерами `openai` и `vllm`.

В нашем тесте (qwen3.8-27b, перевод и 12 анализов) это сократило прогон
с 291 с с пустым анализом до примерно 21 с со всеми заполненными секциями.

## Параллельный анализ

По умолчанию текст сначала переводится, затем анализируется перевод: два
запроса друг за другом.

С флагом `--parallel-analysis` (или `settings.parallel_analysis: true`)
оригинал анализируется одновременно с переводом. Серверы, которые
обрабатывают запросы пачками (vLLM), выполняют оба запроса вместе, и общее
время близко к времени самого длинного запроса.

```bash
llm-translate -c config.yaml -i article.md -f en -t ru --parallel-analysis \
  --sentiment --tags 5 --classify --entities --events
```

Замеры через CLI, en->ru, все 12 анализов, модель уже загружена:

| Модель | Последовательно (по умолчанию) | `--parallel-analysis` |
|---|---|---|
| qwen3.8-27b (рассуждения отключены) | 20,1 с | 13,3 с |
| translategemma-12b | 10,8-11,1 с | 6,9 с |

Тест проводился на одной новостной статье примерно в 900 символов. На
длинных текстах доля перевода растёт, и выигрыш может быть другим.

Что нужно учитывать:

- Промпт анализа просит выдавать свободные значения (теги, сущности,
  события, маркеры) на языке перевода. Фиксированные значения вроде
  `negative` или `economics` остаются на английском.
- Модели выполняют указание языка неравномерно: теги приходят на языке
  перевода, сущности и события могут остаться на языке оригинала.
- Теги по оригиналу могут отличаться от тегов по переводу.
- Если общий анализ падает и CLI переходит на отдельные запросы по каждому
  анализу, указание языка с ними не передаётся.
- Выигрыш заметен, только когда модель уже загружена. Переключение моделей
  в llama-swap стоит минут и перекрывает любую оптимизацию запросов, поэтому
  используйте одну модель и для перевода, и для анализа.

## Другие способы ускорения

- Включайте только нужные анализы: время анализа зависит от числа выходных
  токенов (около 390 для всех 12 анализов).
- Меньшие модели быстрее: translategemma-12b примерно вдвое быстрее моделей
  на 27B, но в наших тестах размечала хуже.
